# giphy-search-engine

## Name
Gary Hermosa

## Descritpion
A responsive web GIF search engine built with HTML,CSS,JavaScript, and the Giphy API.

## Features
- Search for GIFs
- Responsive design 
- Navigation bar
- GIF grid layout 
- Mobile-friendly layout 

## Technologies Used
- HTML
- CSS
- JavaScript
- Giphy API

## Installation Instructions 
1. Clone the repository 
2. Open the project in VS Code 
3. Run with Live Server
